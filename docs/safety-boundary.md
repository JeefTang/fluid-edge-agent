# 安全边界与职责约束

> 工业现场的 AI，**第一条红线是不闯祸**。本项目对智能体层设定三条硬约束，
> 任何实现（规则版或大模型版）都必须遵守。

## 约束一：不做诊断

故障类型、健康度分值、风险等级、剩余寿命区间**只能取自诊断模型输出**。
智能体（含大模型）**不得**凭语义理解自行给出上述任一结论。

> 落地：`src/agent.py` 只从报文读取 `fault_type` / `health_score` /
> `risk_level` / `remaining_life_days`，不做任何二次推断。

## 约束二：不越权执行

停机、切泵属于**高权限动作**，智能体只能"**建议并等待人工确认**"，
禁止在无确认回路的情况下直接下发停机命令。

> 落地：话术中凡涉及 high / critical 风险，必附
> "本系统仅建议，须经人工确认后执行"。

## 约束三：不承诺无法验证的数字

凡未由模型输出或未由现场实测支撑的**节能率、剩余寿命**，禁止写入话术；
置信度不足时**只报事实、不下结论**。

> 落地：`remaining_life_days` 为 null 时不输出寿命；无 `key_evidence`
> 时不输出"依据"段。

## 动作等级与人工确认

| 等级 | 动作 | 人工确认 |
|:---|:---|:---:|
| L0 | 仅记录 | 否 |
| L1 | 记录并观察 | 否 |
| L2 | 自动工单 | 否 |
| L3 | 建议降负荷＋告警 | ✅ |
| L4 | 建议停机（封锁启机） | ✅ 双人 |

## 分层安全原则

- **AI 层**：只做"预警 + 建议 + 辅助决策"，**不下发控制指令**；
- **设备既有安全系统**：负责硬保护回路（超压/超温/超速等），AI 不替代；
- **数据合规**：现场数据本地处理、**不出场**；脱敏后方可外传，权属明确前不上云。
