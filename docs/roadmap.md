# 路线图

> 从一间实训室起步，走向流体设备工厂的边缘智能配套。
> **本仓库当前只覆盖阶段一（PoC）**，阶段二/三尚无公开案例。

## 阶段一 · PoC 与展示（🚧 进行中）

- [x] 旋转机械机理仿真（7 类工况）
- [x] 特征提取（时域 / 频域 / 包络谱，纯 numpy）
- [x] 机理规则诊断（健康度 / 故障类型 / 置信度 / 风险等级）

- [x] 一键演示与可视化

- [ ] 轻量模型（无监督异常检测）对比基线
- [ ] 打包为可在 RK3576 上运行的镜像

## 阶段二 · 高校实训（📋 规划中）

与高校共建 **AI 边缘计算实训室**，定位三重平台：

| 定位 | 说明 |
|:---|:---|
| 人才培养基地 | 培养嵌入式 AI / 边缘计算方向学生，形成人才管道 |
| 队伍练兵场 | 在真实项目（设备接入 / 边缘部署 / 模型训练）中锻炼团队 |
| 技术验证平台 | 受控环境验证模型与方案，积累标准化交付经验 |

配套：demo 样机箱 + 学生实验套件 + 课程与实验指导书。

## 阶段三 · 现场配套落地（📋 规划中）

| 里程碑 | 标志 |
|:---|:---|
| M1 | 首间实训室合作达成，样机箱与实验套件就位 |
| M2 | 首期课程开课，首批学生项目启动 |
| M3 | 首个工厂现场验证完成并出具报告（误报/漏报统计、能效对比） |
| M4 | 形成可报价的"边缘盒子 + 传感器套件 + 看板 + 云管理"配套产品 |

**风险与应对**

1. 现场环境（散热 / 供电 / 干扰）→ 宽压输入 + 电源保护 + EMC 设计；
2. 故障样本稀缺 → 先上机理规则与无监督异常检测，随样本积累迭代；
3. 项目持久性 → 高校合作必须配套课程、导师与项目，避免"只捐硬件"。
